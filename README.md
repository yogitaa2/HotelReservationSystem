# Hotel Reservation System

A console-based Java application for managing hotel rooms and reservations.

## Features

* Display available hotel rooms.
* Categorize rooms as Standard, Deluxe, and Suite.
* Display room prices.
* Book an available room.
* Simulate the payment process.
* Cancel an existing booking.
* View all current bookings.
* Prevent booking of already booked rooms.
* Validate room availability and room numbers.

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Scanner
* Console Application

## OOP Concepts Used

* Classes and Objects
* Constructors
* Encapsulation of room and booking data
* Object creation and management

## Project Requirements

* Design a system to search, book, and manage hotel rooms.
* Add room categorization such as Standard, Deluxe, and Suite.
* Allow users to make and cancel reservations.
* Implement payment simulation.
* Display booking details.
* Use OOP and `ArrayList` to manage room and booking data.

## Room Categories

| Room Type |    Price |
| --------- | -------: |
| Standard  | Rs. 1500 |
| Deluxe    | Rs. 2500 |
| Suite     | Rs. 4000 |

## How to Run

### Compile

```bash
javac HotelReservationSystem.java
```

### Run

```bash
java HotelReservationSystem
```
